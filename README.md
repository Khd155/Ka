# اختبار الكيمياء التفاعلي (Chemistry Quiz App)

تطبيق اختبار تفاعلي مبني بـ HTML / CSS / JavaScript خالص (بدون أي مكتبات خارجية)، تم استخراج أسئلته من ملف PDF لمراجعة نهائية في الكيمياء (الفصلين 2-2 و 2-3)، ويدعم ثلاثة أنواع من الأسئلة:

- اختيار من متعدد (4 خيارات)
- صح / خطأ
- المزاوجة (اختر المفردة المناسبة وضعها في المكان المناسب)

## المحتوى

- **257 سؤال** (143 اختيار من متعدد + 55 صح/خطأ + 59 مزاوجة) توزعت على 6 فصول:
  1. الطاقة والتغيرات الكيميائية
  2. سرعة التفاعلات الكيميائية
  3. الاتزان الكيميائي
  4. الهيدروكربونات
  5. مشتقات المركبات الهيدروكربونية وتفاعلاتها
  6. كيمياء الحياة - المركبات العضوية الحيوية

## كيفية التشغيل

المتصفحات تمنع تحميل ملفات JSON عبر `fetch` مباشرة من نظام الملفات (`file://`)، لذلك يجب تشغيل الموقع عبر خادم محلي بسيط:

```bash
cd /home/user/Ka
python3 -m http.server 8000
```

ثم افتح المتصفح على: `http://localhost:8000`

(أو استخدم أي خادم آخر تفضله، مثل إضافة Live Server في VS Code).

## هيكل المشروع

```
Ka/
├── index.html              # الصفحة الرئيسية (هيكل الواجهة فقط)
├── css/
│   └── style.css           # كل الأنماط، بما فيها الوضع الليلي
├── js/
│   ├── storage.js          # طبقة التخزين المحلي (LocalStorage) فقط
│   ├── quiz-logic.js       # طبقة المنطق (QuizEngine) - لا تلمس DOM إطلاقاً
│   ├── ui.js                # طبقة الواجهة (UI) - كل التعامل مع DOM
│   └── app.js               # الربط بين الطبقات الثلاث + أحداث الأزرار
├── data/
│   └── questions.json       # بنك الأسئلة الكامل
├── images/
│   └── *.svg                 # صور توضيحية (منحنيات طاقة، تراكيب كيميائية)
└── README.md
```

الفصل بين الطبقات:
- **Logic** (`quiz-logic.js`): يدير حالة الاختبار، التنقل بين الأسئلة، تسجيل الإجابات، وحساب النتيجة. لا يعرف شيئًا عن HTML.
- **UI** (`ui.js`): يرسم الشاشات ويستقبل تفاعل المستخدم، ثم يبلغ `app.js` بالاختيار.
- **Storage** (`storage.js`): يقرأ/يكتب فقط من `localStorage` (حالة الاختبار + تفضيل الوضع الليلي).
- **app.js**: يربط الثلاثة معًا (نقطة الدخول الوحيدة التي "تعرف" كل شيء).

## المزايا المطبّقة

- عرض سؤال واحد في كل مرة مع عداد "س من إجمالي".
- شريط تقدّم (Progress Bar).
- دعم الصور داخل الأسئلة (3 أسئلة تحتوي على صور SVG مرسومة بدقة لمنحنيات الطاقة وتركيب الإيثر).
- أزرار التالي / السابق / إنهاء الاختبار.
- شاشة نتائج تعرض الدرجة (مثل 18 / 25)، النسبة المئوية، وعدد الإجابات الصحيحة/الخاطئة.
- مراجعة الأخطاء فقط، أو عرض جميع الأسئلة مع الحلول.
- إعادة الاختبار من جديد.
- حفظ تلقائي للتقدّم في LocalStorage (يمكن استكمال الاختبار إذا أغلقت المتصفح).
- مؤقت اختياري للاختبار (ينهي الاختبار تلقائيًا عند انتهاء الوقت).
- تصفية الأسئلة حسب الفصل (أو كل الفصول معًا).
- الوضع الليلي (Dark Mode) مع حفظ التفضيل.
- تصميم متجاوب (Responsive) يعمل على الجوال.

## كيفية إضافة أو تعديل الأسئلة

كل الأسئلة موجودة في ملف واحد: `data/questions.json`. كل سؤال هو عنصر بالشكل التالي:

### مثال: سؤال اختيار من متعدد (mcq)

```json
{
  "id": 1,
  "chapter": "الطاقة والتغيرات الكيميائية",
  "type": "mcq",
  "question": "تسمى القدرة على بذل شغل أو إنتاج الحرارة:",
  "options": ["القوة", "الضغط", "الطاقة", "الكثافة"],
  "answer": 2
}
```

- `answer` هنا هو **رقم فهرس** الخيار الصحيح داخل مصفوفة `options` (يبدأ من 0). في المثال أعلاه `2` يعني أن الإجابة الصحيحة هي "الطاقة" (العنصر الثالث).

### مثال: سؤال صح/خطأ (tf)

```json
{
  "id": 40,
  "chapter": "سرعة التفاعلات الكيميائية",
  "type": "tf",
  "question": "كلما قلت طاقة التنشيط كان التفاعل أسرع.",
  "answer": true
}
```

- `answer` هنا قيمة منطقية: `true` (العبارة صحيحة) أو `false` (العبارة خاطئة).

### مثال: سؤال مزاوجة (matching)

```json
{
  "id": 199,
  "chapter": "الطاقة والتغيرات الكيميائية",
  "type": "matching",
  "question": "تعتمد طاقة الوضع للمادة على ______.",
  "options": ["تركيبها الكيميائي", "قانون هس", "المحيط", "سالبة", "الحرارة النوعية", "المحتوى الحراري", "الطاقة الحرارية", "موجبة"],
  "answer": 0
}
```

- هذا النوع يمثل تمرين "اختر المفردة المناسبة وضعها في المكان المناسب" من الملف المصدر: كل عبارة من التمرين تتحول إلى سؤال مستقل، و`options` هو بنك المفردات الكامل لذلك التمرين (مشترك ومتكرر بين كل أسئلة نفس الفصل)، و`answer` هو رقم فهرس المفردة الصحيحة داخل `options`.
- تُعرض أسئلة `matching` في الواجهة بنفس شكل أسئلة `mcq` (قائمة رأسية من الأزرار)، وتُصحَّح بنفس الطريقة (مطابقة الفهرس).

### إضافة صورة لسؤال (اختياري)

أضف حقل `"image"` يحتوي على المسار النسبي للصورة:

```json
{
  "id": 21,
  "chapter": "سرعة التفاعلات الكيميائية",
  "type": "mcq",
  "question": "بالنظر إلى منحنى طاقة التفاعل التالي، صنّف نوع التفاعل:",
  "image": "images/energy-curve-1.svg",
  "options": ["طارد للحرارة", "ماص للحرارة", "الطاقة الممتصة", "متساوٍ في الطاقة"],
  "answer": 1
}
```

### قواعد عامة عند التعديل

- يجب أن يكون `id` رقمًا فريدًا غير مكرر.
- `type` يجب أن تكون بالضبط `"mcq"` أو `"tf"` أو `"matching"` (أي نوع آخر غير مدعوم في الواجهة).
- أسئلة `mcq` يجب أن تحتوي على 4 خيارات بالضبط داخل `options`. أسئلة `matching` يمكن أن تحتوي على أي عدد من الخيارات (بحسب حجم بنك المفردات في التمرين المصدر).
- بعد أي تعديل، تحقق من أن الملف JSON صالح (لا توجد فواصل زائدة أو أقواس ناقصة) — يمكنك استخدام أي أداة فحص JSON عبر الإنترنت أو الأمر:

```bash
python3 -c "import json; json.load(open('data/questions.json', encoding='utf-8')); print('OK')"
```

## ملاحظات تقنية

- جميع البيانات مأخوذة من ملف PDF مصدري كان يستخدم تلوين الإجابة الصحيحة باللون الأحمر (لأسئلة الاختيار من متعدد) ورمزي ✓/✗ (لأسئلة الصح والخطأ) كمفتاح إجابات، وتم استخراجها وفق هذا المرجع بدقة.
- تم تجاهل أي نوع سؤال آخر غير اختيار من متعدد وصح/خطأ بالكامل، طبقًا للمطلوب.
- الصور (`images/*.svg`) رسوم متجهية (SVG) مُعاد إنشاؤها يدويًا بدلاً من اعتماد صور منخفضة الجودة من ملف PDF الأصلي، لضمان وضوحها على جميع الشاشات.
